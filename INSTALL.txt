Contradiction - Cinematic Android edition v0.10

Requires Android 8.0 or later. Update the existing installation to retain
the imported video, resume progress and both manual save slots.

INSTALL
Install Contradiction-Android-v0.10.apk. On the first installation, copy the
original Windows/gfx/MCMV.mp4 to Downloads and choose Import game video.
Wait for Import complete, then the Downloads copy can be deleted. Import
needs approximately 2.4 GB of additional free space while copying.
An existing imported video is reused automatically after an APK update.

PLAY
Begin or continue from the title screen. Fresh investigations and confirmed
new-game resets play the original prologue first. Skip prologue proceeds
directly to the investigation. Watch prologue on the title screen replays
it without resetting progress. Pause and background/resume also work while
watching the prologue.

The film fills the app viewport;
Original frame preserves the entire image, and Fill display in Settings
crops the edges to fit wide displays. Video and audio are not re-encoded.

Tap the original hand-drawn arrows to explore. Their visible artwork is
small, with larger invisible tap targets. Casebook and Map are minimal
icons alongside Captions and Pause at the top. Search appears in the scene
only when investigation is available, using the original magnifying-glass
art. There is no bottom dock. Controls clear away during scenes.

CASEBOOK: browse collected evidence, recorded events, contradictions and
advice from the Chief. Select an item to read its description and notes.
MAP: select an original-art marker or a location in the list, then Travel.
INTERVIEW: select evidence, ask the witness, then tap recorded statements
to compare them. Statements may concern different evidence. Compare two
conflicting statements to trigger the original deduction and story event.
PAUSE: opens the title screen and pauses video, audio and story timers.
CASE FILES: store or load either manual slot with explicit confirmation.
ANDROID BACK: closes the current pane, returns from replay, or opens pause.

Captions, framing, music volume and video import are in Settings. Both
landscape orientations are supported; portrait and browser gestures are
disabled. The UI respects camera cutouts and has no reserved bottom strip.

SAVE DATA
Progress saves when the app is backgrounded. Original saves resume from
stored chapter/location progress rather than an exact video frame.
New investigation resets story progress after confirmation, and retains
the two manual save slots. Clearing app data or uninstalling removes all
saves and the imported video. Updating the APK retains them.

VALIDATION
Touch integration tests cover fullscreen layouts, pause timing, evidence,
save/cancel/load/reset, original-map travel, Chief advice, questioning,
valid cross-evidence deductions, resume saves and gesture suppression.
Layout checked at 960x540, 832x384 and 676x320 CSS pixels. Native fullscreen,
camera-cutout spacing, Android Back and the JavaScript bridge checked on
the connected S25+. A full end-to-end story playthrough is not yet tested.

BUILD
Run powershell -ExecutionPolicy Bypass -File .\build.ps1.
Use -Variant Debug for on-device WebView inspection. Release builds disable
WebView debugging and retain the existing prototype signing identity.
Original game assets are provided locally; see README.md for build setup.
